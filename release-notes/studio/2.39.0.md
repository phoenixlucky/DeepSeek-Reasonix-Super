This release adds double-click rename for sessions, starting without any model service, a low-disk-space warning and maps and dashboards in extension surfaces, and tidies the sidebar and conversation display.

## New

- Double-click a session row in the sidebar to rename it in place; the rename dialog can generate a title on request (#12977, #11591)
- Reasonix starts without any model service configured and opens the connection guide directly (#12966)
- A warning appears when the disk holding a project or session is nearly full; on by default, it only warns and never deletes files (#12960)
- The terminal UI reports working, waiting-for-you and finished states to the terminal (#12976)
- A finished session can stay in the Running list for a chosen time; off by default (#12957)
- The sidebar marks sessions stored by 1.x, and the terminal resume list marks sessions you have not viewed (#12405, #12587)
- A skill invoked with / shows as a compact skill block, and the JSON input of tool calls is syntax-coloured (#12972, #12969)
- Files can be staged and unstaged from the changes list (#12923)
- The application icon shows the count of unread finished tasks, and a new flat icon replaces the old one (#12922, #12897)
- New "Clear blue" and "Tea green" colour schemes; theme packs can declare density and corner radius (#12932, #12513)
- The icon rail has a New session button; clicking the folder mark in the title bar opens the project folder (#12891, #12857, #12288)
- File links in a conversation open in the workbench, and the file menu can add a file or folder to the conversation (#12910, #12877)
- Remote machines are gathered into one collapsible row, and the levels of the session tree are easier to tell apart (#12878, #12905)
- Esc must be pressed a second time to stop a running turn (#12859)
- Extension surfaces support style fields, editable drafts, map-versus-dashboard views and non-blocking actions (#12830, #12854, #12876, #12896)
- Installed packages can be searched by capability, show their contribution types, copy their invocation, and the install preview shows the resolved commit (#12065, #12117, #12070, #12075, #12098)
- You can view a sub-agent's skill declarations and search an MCP server's tool list (#12102, #12085)
- WSL distributions are discovered and one of them is probed (#12595)
- The phone page can be added to the home screen; paired phones survive a restart, with a switch in settings (#12591, #12440)
- Linux arm64 .deb and .rpm packages are published (#12914)
- Local stdio MCP servers receive the working directory and the host's read-only state (#12967)
- The tool catalogue refreshes automatically when an MCP server adds or removes tools at runtime and sends a notification (#12138)
- The host's check of changed turns can be turned off (#12860)
- Right-to-left text blocks are displayed in their own direction (#12118)
- The workbench browser-tab menu gains "Close browser tabs to the right", reachable by keyboard (#12557)

## Changed

- The Versions page keeps only the latest few earlier versions and folds the rest behind a button (#12982)
- Session lists use single-line ellipsis everywhere, and bulk selection moved to the "This machine" more menu (#12935)
- The desktop sidebar uses divider bars for its actions, and the brand mark is the official wordmark throughout (#12918, #12936)
- Computer use now runs on the CUA Driver (#12937)
- The "Execution" block in a conversation is a faint single line, and its header sticks to the top when expanded (#12954, #12944)
- The session title in the title bar sits next to the project name, and the branch button's hover shape matches its neighbours (#12955, #12971)
- The model list keeps only the settings page's own scrollbar, and the display-alias input follows the theme (#12979)
- Installed skills are grouped by source (#12329)

## Fixed

- Folded user messages no longer vanish entirely when compaction cannot get a summary (#12963)
- The context-usage figure now uses the same number the compaction trigger uses, instead of reading lower than the provider reports (#12991, #12988)
- On Windows, clicking a task-completed notification brings the window to the front, and the click path is logged (#12907, #12956)
- Closing a browser tab no longer reads content the kernel never sends (#12886)
- A question you have started answering no longer times out and is skipped (#12884)
- A turn in progress is kept when the runtime is rebuilt or a turn-end event is lost (#11735)
- Saving settings now reports success, not applied, and failure separately, and a failure can be retried (#12350)
- The undo entry is restored from the backend, and an expired-undo state is kept (#11589)
- Unsaved file drafts in the workbench are kept (#12898)
- Context usage refreshes immediately after switching model settings (#12871)
- Cost is shown in the wallet's currency, and the folder picker can list hidden folders (#12874)
- On Windows, when the Git Bash probe hangs it is retried once, and the fallback shell path is shown correctly (#12887)
- When only /skill-name is sent, history records exactly what you typed (#12890)
- Duplicate MCP tool names are refused, and the original identifier stays the same on every path (#12889, #12893, #12892)
- Sub-agent status frames are no longer lost when the client falls behind (#12888)
- File preview checks that the target may be accessed, and passes through the PreToolUse hook first (#12115)
- A failed memory save is rolled back, and a migrated memory repairs its index when changed again (#12938, #12939, #12940)
