本版新增模型读图片/视频工具、网页搜索与抓取的后端设置、会话间消息的真开关与派活、打开本地网页文件和模型接口重试次数设置，并修复子代理、MCP、侧栏、输入法与反馈回复相关的一批问题。

## 新增

- 设置 > 外观 > 大小 增加“界面文字”四档，只放大侧栏、设置、标签等处的文字，不动边距和控件；对话正文仍由“正文”单独设置。关联 #11577。
- MCP 工具定义被改动时不必每次点接受：可以对某个服务器选择「跟随」，它的改动直接采用，每次仍会通知；随时可取消。关联 #12356。
- 需要登录（401）的 MCP 服务器行上有“登录”按钮，点后等待浏览器登录；被暂挡工具旁新增“接受并以后都自动接受这个服务器的改动”，已跟随的服务器可“取消跟随”。关联 #12357。
- 「我的反馈」的等级卡片里加了一句说明，写清楚「已落地」指反馈已被修复或实现并随新版本发布。修复 #12900。
- 新增（默认关闭）：模型可把任务交给你另一个项目里的会话（dispatch_to_project），对方用户批准后才看到。关联 #13341。
- 你发过消息的会话，侧栏行和标签上会出现小图标，标明对话走到哪一步（等批准、处理中、已回复、被拒绝），点它跳到该会话。关联 #13371。
- 设置里有真正的“会话间消息”开关；被拦下的消息可“批准并记住项目”，已记住的项目在设置里一键撤销。保存后下个回合起生效。关联 #13371。
- 声明 `video_models` 和 `video_protocol` 后，`read_video` 可把 MP4 原生交给能看视频的模型（通义内联、Kimi 上传），卡片显示发给了哪个模型。关联 #13399。
- 能读图的模型多了 view_image 工具，可直接看工作区里的 PNG/JPEG/GIF/WebP 文件；不读图的模型不受影响。关联 #13540。
- 本机读不到网页时，`web_fetch` 可回退到 DeepSeek 付费抓取接口，需先在卡片上同意；内网地址绝不外发。关联 #13541。
- 免费搜索没有回答时，`web_search` 可回退到 DeepSeek 付费搜索接口；首次使用前弹出卡片，写明价格和搜索词，由你同意。关联 #13541。
- `web_search` 可用你自己运行的 SearXNG 免费搜索，在用户配置里设置，默认关闭。关联 #13541。
- 设置 > 工具与权限 里可设置网页搜索和抓取的后端与先后顺序；付费后端的计费同意是单独的开关，不会替你勾选。新开的窗格生效。关联 #13551。
- 对话里点一个你授权过的额外文件夹里的文件路径，现在能在工作台里只读打开它（不能保存）；文件夹之外的路径仍打不开。关联 #13582。
- 新增用户设置 `agent.max_provider_retries`：模型接口连接失败后的重试次数，默认仍是 10；设为 0 则一直重试到你取消，适合无人值守的长任务。关联 #13526。
- 目标现在显示用量：桌面端展开计划栏能看到状态、轮数、请求数、tokens 和用时，停下时说明原因；终端页脚同样显示。关联 #13663。
- 工作台浏览器里打开本地网页、SVG 或 PDF 文件时，右上角按钮可用系统默认程序打开它，旁边注明网页脚本会照常运行。关联 #13665。
- 编辑器（ACP）新增只读方法 `session/info`（模型、工作区、预设、自动放行、缓存）和 `session/mcpServers`（已配置的 MCP 服务器及启用状态）。关联 #13644。
- 编辑器（ACP）可对单个会话重连、断开 MCP 服务器，并提交扩展表单；项目声明但未获批准的服务器不会被启动，只返回要运行的命令。关联 #13660。
- 编辑器（ACP）里付费搜索、付费抓取的同意可以选“本会话允许”或“始终允许”（存进你的设置），重连后卡片上仍保留这个选择。关联 #13606。

## 变更

- 输入框恢复 1.x 手感：悬停或聚焦时边框扫过一圈光（运行中、系统减弱动画时不播）；框内不再印“空闲/运行中”，状态仍读给读屏软件，运行时钟照旧。关联 #13253。
- 选了人民币或美元显示费用、但模型价格不是官方价目表里的价格时，设置里会说明哪些模型无法换算；服务商页的价格行提供「恢复官方价」，缓存命中价为 0 时提示费用偏低。关联 #13513。
- 子代理并发数和并行写者数默认不再限制（原为 6 和 3），可在用户配置里设上限；嵌套深度默认 8，设 0 取消。关联 #13526。
- 会话队列不再限制排队 64 条；想限制时在用户配置里设 `agent.max_queued_inputs`，队列的字节上限仍然生效。关联 #13526。
- 侧栏不再限制只能记住 32 个项目；想限制时在用户配置的 [desktop] 里设 max_workspaces。关联 #13526。
- 左上角品牌标志旁的“STUDIO”徽标由实心深色块改为透明底、细边框、淡色文字，不再像一条提示；外形尺寸不变。关联 #13601。
- MCP 登录：打开浏览器之前先告诉你服务器要把你带去哪个主机，批准后才打开；可选“始终允许”，只对这个服务器和这个主机生效。关联 #12357。
- `/peer` 和会话间消息的接口现在会说明你发出的消息处于等待、处理中、已回复还是被拒绝。关联 #13341。
- 带图片的排队消息不能在运行中途插入，要等本轮结束；队列里这一行现在写明“含图片，本轮结束后发送”，不再只显示“尚未送达”。关联 #13563。
- 子代理列表里已结束的任务现在写明状态“已交付”并带上耗时，用绿色标出，不再只显示一个秒数。关联 #13596。
- 配置工作目录时会显示准备的实际阶段、长时间等待、成功、失败重试和取消；失败或取消保留原任务与附件，已有隔离目录也在同一入口可搜。关联 #13598。

## 修复

- 压缩摘要复用已发送的系统提示和工具目录；纯文本历史还复用对话前缀，含工具的历史继续脱敏。关联 #11860。
- Windows SSH 远端通过脚本文件启动内核，避免 WMI 的编码命令启动失败，并正确处理中文路径。关联 #12750。
- 修复输入“/”后技能列表出现很慢的问题（装了大量插件技能时尤其明显）：短时间内的重复补全不再逐个重读技能文件。关联 #13197。
- 辅助会话可收起为标题栏以露出正文，展开后保留草稿、引用和回答；收起不会取消正在进行的请求。关联 #13288。
- 同一仓库里多个项目声明同名 MCP 服务器（内容不同）时，各自启用互不覆盖，重启后都保持已启用。关联 #13527。
- 共享事件流迟迟打不开时（旧版内核或代理不认这条路径），窗格 10 秒后改读各自的事件流，页面不再停在“已连接却收不到事件”。关联 #13562。
- 辅助会话面板改为从输入框上方弹出，不再固定在右上角、盖住右侧文件树；按 Esc 或点 × 关闭后焦点回到辅助会话按钮。关联 #13539。
- 两个窗口或项目用同名但启动方式不同的 MCP 服务器时，不再每次启动互相冲掉握手缓存。关联 #13560。
- 没有代理、读不到版本目录时，打开设置页会让「版本」等上 15 秒；现在各处共用一次读取，失败只记 20 秒，点「重试」才重新读。关联 #13565。
- 原目录和隔离目录的会话归入同一项目，并标出实际目录；原目录失效时使用仍存在的目录，手动选择隔离目录仍打开该目录。关联 #13586。
- 同一文件夹被写成不同形式（大小写、斜杠方向、末尾分隔符）时，窗格与侧栏项目对不上，标签和列表可能缺少已打开标记；窗格的会话找不到列表行时，日志里会留一行说明。关联 #13600。
- 断网恢复后，侧栏“进行中”计数不再卡在已经结束的会话上（没打开的窗格也会在网络恢复后重新读到状态）。关联 #13604。
- agent 打开、刷新或翻页内置浏览器时，不再打断你正在进行的输入法输入（拼音不会被当成字母直接上屏）。关联 #13605。
- agent 打开、导航或显示内置浏览器页面时，不再把你正在输入的键盘焦点抢走；你自己点进那个页面则照常。关联 #13605。
- 设置页左侧已选中的分区，鼠标停在上面时不再被悬停样式盖掉：浅色主题保持选中底色，两种主题下图标都保持选中时的颜色。关联 #13610。
- 反馈刚提交、状态还是“已收到”时，如果维护者已经留言提问，现在可以直接在这条下面回复，不必等它被登记为 GitHub 议题；审核中的反馈仍不能回复。关联 #13626。
- 主会话的模型不读图、子代理的模型读图时，子代理现在也有 view_image 可以看图，不再错用视频工具；父会话的工具表不变。关联 #13642。
- 命令行里输入斜杠命令时，同一条技能发现警告不再每次按键重复打印、盖住输入行和状态栏；每条警告每个会话只出现一次。关联 #13655。
- 后台任务一段时间没往自己的输出里写内容时，界面上的警告改成中文，写明任务名和已安静的时长，不再显示英文原文。关联 #13566。
- 多个会话同时运行时，超长输出偶尔被截断的问题。关联 #13620。
- Windows 上默认端口落在系统保留段（Hyper-V、WSL、Docker）时，网页服务现在会顺延到下一个可用端口，不再直接启动失败。关联 #13649。
- 网络抖动时读取窗格列表失败，不再关掉所有标签并把你切到别的窗格；共享事件流首次连上后若断开，重连不再漏掉中间的事件。关联 #13603。
- 会话标题在后台生成时，首条消息改了会重新生成，较慢的旧结果不会盖掉新标题。关联 #13611。
- 网络、壁纸和账号面板失败时，按界面语言说明原因：不支持的壁纸格式、被拒绝的代理、登录请求已过期都不再显示英文原文或路径加状态码。关联 #13621、#13637。
- 会话收件箱的队列暂时读不出来时，不再当成空队列而停止投递，会稍后重试。关联 #13438。
- Windows 上读取 PDF 引用超时被取消时，不再因为结束进程命令无响应而卡住。关联 #13614。

## 升级须知

This release adds image and video reading tools for the model, web search and fetch backend settings, a real switch and dispatch for session messages, opening a local page in the default program and a provider retry setting, and fixes a batch of sub-agent, MCP, sidebar, IME and feedback-reply problems.

## New

- Appearance > Size has an Interface text step (small to larger) that enlarges only sidebar, settings and tab text, not spacing or controls; body text keeps its own. Refs #11577.
- For an MCP server you trust, choose to follow it: its changed tool definitions are taken without a click, each still announced, and you can undo it. Refs #12356.
- an MCP server that answered 401 has a Sign in button; withheld tools gain "accept and follow this server's changes", and a followed server can be un-followed. Refs #12357.
- the My feedback level card now says what "shipped" counts: a report that was fixed or built and released in a version. Fixes #12900.
- the model can hand a task to a session in another of your projects (dispatch_to_project); that project's user approves first. Refs #13341.
- a session you have written to carries a small icon on its row and tab saying where the exchange stands (waiting, working, replied, declined); click it to open that session. Refs #13371.
- Settings has real session-message switches; a held message can be approved with its project remembered, and revoked in Settings. Applies from the next turn. Refs #13371.
- declare `video_models` and `video_protocol` and `read_video` hands an MP4 to a model that watches video (DashScope inline, Kimi upload); the card shows which. Refs #13399.
- a model that reads images gets a view_image tool that shows it a PNG, JPEG, GIF or WebP file in the workspace; text-only models are unchanged. Refs #13540.
- when this machine cannot read a page, `web_fetch` can fall back to DeepSeek's paid Fetch API after you agree on a card; internal addresses are never sent. Refs #13541.
- when the free search did not answer, `web_search` can fall back to DeepSeek's paid Search API, after a card shows the price and the query and you agree. Refs #13541.
- `web_search` can use your own SearXNG instance for free searches, set in your user config, off by default. Refs #13541.
- Settings > Tools and permissions sets the web search and fetch backends and their order; consent to be billed is its own switch, never ticked for you. New panes only. Refs #13551.
- A path in the conversation that points into an extra folder you granted now opens read-only in the workbench (no saving); a path outside every granted folder still does not open. Refs #13582.
- Added the user setting `agent.max_provider_retries`: how often a failed provider connection is retried, still 10 by default; 0 keeps trying until you cancel, for long unattended runs. Refs #13526.
- A goal now shows its usage: the desktop plan fold lists state, turns, requests, tokens and work time and says why it stopped; the terminal footer shows the same. Refs #13663.
- A local HTML, SVG or PDF file in the workbench browser can now be opened in the system default program from the toolbar button; a note says page scripts run as usual. Refs #13665.
- ACP gains read-only `session/info` (model, workspace, preset, auto-approve, cache) and `session/mcpServers` (configured servers, on or off, no commands). Refs #13644.
- ACP can reconnect or disconnect an MCP server for one session and submit extension forms; a project-declared server that is not approved is never started, only its command is reported. Refs #13660.
- In editors (ACP), consent to paid search or fetch can be given for the session or always (saved to your settings), and a reconnected card keeps that choice. Refs #13606.

## Changed

- the composer border sweeps with light on hover or focus as in 1.x (not while running or with reduced motion); the idle/running word is no longer printed but still announced. Refs #13253.
- Settings names models whose price is not in the vendor's list and so cannot be converted to the pinned currency; the price row offers Restore official price. Refs #13513.
- Sub-agent concurrency and parallel writers are no longer capped by default (were 6 and 3); set limits in your user config. Nesting depth defaults to 8; 0 removes it. Refs #13526.
- The session queue no longer stops at 64 waiting prompts; set `agent.max_queued_inputs` in your user config to limit it, and the queue's byte limits still apply. Refs #13526.
- The sidebar no longer stops at 32 remembered projects; set max_workspaces under [desktop] in your user config to limit it. Refs #13526.
- The STUDIO badge beside the wordmark is now an outline with muted text instead of a solid dark block; its size is unchanged. Refs #13601.
- MCP sign-in names the host a server sends you to and asks before the browser opens; "always" is remembered per server and host only. Refs #12357.
- `/peer` and the messages-between-sessions API now say whether a message you sent is waiting, being worked on, replied to or declined. Refs #13341.
- A queued message with a picture cannot join a running turn and waits for it to end; its queue line now says "Has an image: sent when this turn ends", not just "not delivered yet". Refs #13563.
- A finished sub-agent in the list now says "Handed back" with its time, in green, instead of showing only a number of seconds. Refs #13596.
- Preparing a workspace shows its real stages, success, retry and cancel; a failure or cancel keeps the task and attachments, and existing worktrees are searchable there. Refs #13598.

## Fixed

- Compaction reuses the sent system/tool prefix, plus eligible text history. Tool arguments remain elided and oversized or stale requests fall back. Refs #11860.
- Windows SSH remotes launch the kernel from a UTF-8 script instead of a WMI encoded command, preserving non-ASCII paths. Refs #12750.
- Fixes the slow skill list after typing "/" (most visible with many plugin skills installed): repeated completions within a moment no longer re-read every skill file. Refs #13197.
- Collapse a side question to read the transcript without losing its draft, quotes, answers or pending request. Refs #13288.
- projects of one repository that declare an MCP server by the same name with different contents keep their enables side by side across a restart. Refs #13527.
- when the shared event stream never opens (an older kernel, or a proxy), panes read their own streams after 10 seconds instead of staying silent. Refs #13562.
- the side-conversation panel now opens above the composer instead of sitting at the top right over the file tree; Esc or the close cross returns focus to its button. Refs #13539.
- two windows or projects using an MCP server of the same name but a different launch spec no longer evict each other's handshake cache on every start. Refs #13560.
- With no proxy and an unreachable version catalog, opening Settings kept Versions waiting 15 s; callers now share one read, a failure is kept 20 s, and Retry reads again. Refs #13565.
- source and worktree chats share one project with checkout labels. A surviving checkout replaces a missing source; picking a worktree still opens it. Refs #13586.
- A folder spelled two ways (case, slashes, trailing separator) no longer splits a pane from its sidebar project; a pane with no row for its conversation now leaves a log line. Refs #13600.
- after a network flap the sidebar's running count no longer sticks on conversations that finished; a pane you have not opened reads its status again once the network is back. Refs #13604.
- the agent opening, reloading or navigating the built-in browser no longer cuts off an input-method composition in progress (the pinyin is no longer committed as raw letters). Refs #13605.
- the agent opening, navigating or showing a built-in browser page no longer takes the keyboard from what you are typing in; clicking into that page yourself still works. Refs #13605.
- The selected settings section keeps its look while the pointer rests on it: its fill in the light theme, and its icon colour in both themes. Refs #13610.
- A "received" report can be answered from its thread once a maintainer has written to it, without waiting to be filed as an issue; one under review still takes no reply. Refs #13626.
- A sub-agent on an image-reading model now gets view_image even if the session's model cannot read images; the parent's tool block is unchanged. Refs #13642.
- Typing slash commands no longer reprints the same skill-discovery warning on every keystroke over the input line and status bar; each warning appears once per session. Refs #13655.
- the warning about a background job that has been silent on its own output is now worded in the interface language, with the job name and how long it has been quiet. Refs #13566.
- Oversize output was occasionally truncated when several sessions ran at once. Refs #13620.
- On Windows, when the default port falls in a range the system reserves (Hyper-V, WSL, Docker), the web server now moves on to the next free port instead of failing to start. Refs #13649.
- A failed pane-list read in a network blip no longer closes every tab, and a shared stream that drops right after its first attach no longer loses events. Refs #13603.
- Session titles generated in the background are asked again when the first message changes, and a slower older result no longer overwrites the newer title. Refs #13611.
- Network, wallpaper and account panels word their failures in the interface language instead of English text or a path and a status. Refs #13621, #13637.
- When the session inbox queue cannot be read for a moment, delivery no longer stops as if it were empty; it retries shortly. Refs #13438.
- On Windows, cancelling a timed-out PDF reference extraction no longer hangs when the process-kill command does not answer. Refs #13614.

## Upgrade notes

- No action is needed. The only default that changed is that sub-agent concurrency and parallel writers are no longer capped; set limits in your user config to keep them. Refs #13526.
