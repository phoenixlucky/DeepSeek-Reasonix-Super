本版用 Go 1.26.10 重新构建，修复标准库证书验证对已不再受信任的中间证书的处理，并修好历史搜索读不到会话时误报“没有匹配”和多进程下会话从搜索里消失的问题。

## 修复

- 构建改用 Go 1.26.10，修复标准库证书验证 crypto/x509 对已不再受信任的中间证书的处理（GO-2026-6809）。关联 #14034。
- 会话记录读不出来时，历史搜索不再说「没有匹配」，而是先提示索引不完整，并把该会话标为损坏、稍后自动重试。关联 #14023。
- 两个进程共用一个历史索引时，另一个进程刚索引的会话不再被误判为「已删除」而从历史搜索里消失；只有确认文件不存在才会被标记缺失。关联 #14024。
- 侧栏“项目”标题行里的“+”和“更多操作”按钮悬停时现在是同一种高亮。关联 #14041、#14043。

This release is rebuilt with Go 1.26.10, which fixes how certificate verification treats intermediate certificates that are no longer trusted, and fixes history search reporting no match for an unreadable transcript or losing a session another process had just indexed.

## Fixed

- builds now use Go 1.26.10, which fixes how crypto/x509 certificate verification treats intermediate certificates that are no longer trusted (GO-2026-6809). Refs #14034.
- when a session's transcript cannot be read, history search no longer claims a miss; it says the index is incomplete, marks that session corrupt, and retries on the next scan. Refs #14023.
- with two processes sharing one history index, a conversation the other process just indexed is no longer swept as deleted; only a file confirmed gone is marked missing. Refs #14024.
- The sidebar's Projects header now highlights the "+" and more-actions buttons the same way on hover. Refs #14041, #14043.
