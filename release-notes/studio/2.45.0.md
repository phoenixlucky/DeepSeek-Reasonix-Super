本版新增定时任务、会话排序与跨项目移动、手机提醒、WSL 远程、Git 面板、反馈贡献榜、规则目录与按名称关闭工具，推理强度可在进行中的回合里切换，并修复内置浏览器页面缩放、终端卡顿、子代理识图等一批问题。

## 新增

- `reasonix schedule add|list|tick` 等命令，在终端确认后按时间只读地运行任务；需用系统计划任务调用 `schedule tick`。关联 #11406。
- Studio 打开且可见（窗口或托盘图标）时，会按计划自动运行已确认的定时任务；同一时刻只有一个内核执行。关联 #11406。
- 会话菜单里可以把会话上移或下移，也可以在会话行上按 Alt+上下键；顺序保存在内核里，重启后不变。关联 #11420。
- Linux 增加 `.AppImage` 下载（amd64 和 arm64），可直接运行；它不会自更新，新版本需重新下载。关联 #11653。
- 浏览器和工作台可以全屏查看，会话与输入框暂时收起，按 Esc 或再点一次回到分栏；有事等你决定时自动退出全屏。关联 #11721。
- 登录同一账号的手机可在有操作待批准、模型提问、一轮出错时收到提醒，通知只含类别和数量。电脑和手机两边默认都关，需分别开启。关联 #11878。
- MCP 服务器因授权范围不够拒绝调用时，模型会停下，你可在该服务器那行点“授权更多权限”，每次都会先问你。关联 #11959。
- 在“我的反馈”里可以撤回自己的反馈（命令行用 /feedback withdraw）；已登记的议题会被关闭，已有结论的反馈不能撤回。关联 #11995。
- 可选的等级提示（设置里“等级提升时通知我”，默认关）：反馈等级提高时在窗口顶部提示一次，终端 /feedback list 说一行。关联 #12025。
- 在“我的反馈”的对话里，你自己的回复旁会显示你的等级徽章，维护者的回复旁没有。关联 #12025。
- 关联账号的电脑上，“我的反馈”会列出其他已关联设备的反馈和回复；终端新增 /feedback link、unlink、links。关联 #12073。
- 设置 → 远程可以添加本机的 WSL 发行版：内核运行在发行版里，界面仍在 Windows；关闭 Studio 后内核随发行版停止，对话会保留。关联 #12225。
- 终端界面的 /mcp 面板里，返回 401 的服务器可按 a 登录，要求更多权限的服务器可按 u 授权，都会先问你。关联 #12357、#11959。
- ACP 会话支持 `additionalDirectories`，多文件夹工作区可让会话写入额外文件夹，仅限该会话，且经过与手动授权相同的检查。关联 #13114。
- ACP 支持 `$/cancel_request`、消息块 `messageId`、权限请求带工具名，并按客户端声明转交 MCP 的表单与外部页面。关联 #13114。
- 可选的追踪导出，在用户配置里开启并填写收集器地址后，每轮对话以 OpenTelemetry 追踪发给你自己的观测系统；默认关闭，只发结构和名称。关联 #13115。
- 反馈面板里的“贡献榜”，按版本有名次，自己选择加入并预览名字，随时退出；终端用 /feedback board。服务端开启后才显示。关联 #13142。
- 会话菜单里可以把会话移到另一个项目，只带走对话和标题、置顶、归档；权限设置、检查点、后台任务日志和排队消息不随移动，原件会被移除。关联 #13370。
- 设置里的 SearXNG 地址旁新增「测试连接」，说明连不上的原因；只测已保存的地址，不连云元数据等地址；搜索失败时模型也收到同一原因码。关联 #13541。
- 大文件优先引用本地路径，无路径时流式上传；默认 1 GiB 上传安全上限可由用户配置调整。关联 #13544。
- 实验性，未经真实端点验证：原生 Gemini 提供方（Interactions API），支持思考、工具调用与视频（含 Files API）。关联 #13615。
- 可在设置里打开“把视频地址交给模型厂商”（默认关闭）；只交你亲手写的 https 地址，厂商自己访问，智谱 GLM 与 Gemini（YouTube）支持。关联 #13616。
- 子代理的面板行、完整记录标题和嵌套卡片都会显示它实际跑在哪个模型和强度上，失败或中断的也有。见 #13640。
- 模型现在可以请你打开它需要的开关（比如派发到其他项目），你点一下确认才生效；安全边界类设置它永远改不了。关联 #13678。
- 在输入框输入 # 可选一段本工作区的历史会话，作为只读资料带进这条消息；搜索命中也能引用，长度上限可在设置里调。关联 #13687、#11942。
- 模型可用 task 的 task_id 给运行中的子代理补充指示，它在下一次调用工具时读到；设置里可调单条大小和每分钟上限。关联 #13693。
- mod 的安装预览写明完全信任与静态清单；mod 可在输入框上方画一条带，它的提问会写明来源。关联 #13694。
- 把鼠标移到你发的消息上，操作图标旁会显示这条消息的发送时间，长时间运行的任务可以据此核对起止时间。关联 #13697。
- 设置 → 扩展里，你自己和项目文件夹里的技能多了「卸载…」，确认框写明要删除的位置；内置技能和由包提供的技能不显示。关联 #13714。
- 终端里的 /mcp 面板现在可以添加和删除 MCP 服务器（按 n、d），添加前会完整显示将要运行的命令并要你确认。关联 #13754。
- 工作台里的 Git 面板：改动按文件夹树显示，可整个文件夹暂存、丢弃单个文件的改动，推送前先预览目的地，历史里的提交可展开看文件和差异，非仓库的项目文件夹会按仓库分组显示。关联 #13821。
- 终端里 /btw <问题> 在旁路问一个只读问题，答案只显示一次，不存入会话、不进入提示词。关联 #7950。
- `reasonix acp --permission-mode` 供把 Reasonix 当子代理嵌入的宿主使用：固定审批姿态，客户端只能降低不能抬高，旧存档的更高姿态被限制且文件不改。议题 #13839。
- 连接可以声明余额接口的返回格式；其他域名（如中转站）必须选择格式，否则显示未配置，也不发密钥。关联 #13736。
- 设置里可以让新对话默认进入计划模式（agent.default_mode，默认关闭）；已有对话保持自己的模式。关联 #7852。
- 状态栏显示当前按供应商哪个时段计费（高峰或平峰）和还有多久切换，只在模型用的是供应商自己的价格表时显示。关联 #8853。
- Studio「人设」页提供用户级前后缀及运行时上下文开关；内置指令保留，项目不能设置人设。保存后在新会话或下次会话重建时生效。关联 #13588。
- 连接编辑器里，每个模型价格下可填价格来源链接和核对日期（UTC）；只显示主机名，点击才打开，不会自动访问。议题 #13276。
- 支持规则目录（.reasonix/rules、.claude/rules 和用户目录下的 rules），可用 paths: 限定到某些文件；不影响缓存前缀。关联 #9886。
- 可以按名称关闭工具（[tools] disabled，设置里每个工具有开关），关闭后不再发给模型，调用会被拒绝；被其他功能依赖的保留并提示。关联 #8394。

## 变更

- 服务商支持逐请求设置思考强度时，切换强度不再重建会话，进行中的回合里也能切，下一次请求起生效。见 #11411。
- 会话等你回答时（含 Auto Guard 确认卡、沙盒越界提问）让出写入权；其间别的会话占了这些路径，会告知模型并记入回执，最长等待可设。见 #11531。
- task 工具新增 task_id 参数，升级后的第一轮对话，工具说明的缓存会冷一次，之后恢复。关联 #13693。
- 通过 ACP 连接时，失败的对话回合改为以 JSON-RPC 错误（-32603，data.code 为 turn_failed）结束，不再返回规范之外的 stopReason "error"。关联 #13703。
- 通过 ACP 连接时，模型缺少密钥或尚未配置提供方，新建会话返回协议规定的“需要认证”错误（-32000），客户端可据此引导运行 reasonix setup。关联 #13705。
- 通过 ACP 连接时，因“尚未验证”被暂停的回合以 end_turn 结束，响应带 paused 结果，文本末尾追加 [paused] 回执。关联 #13706。
- 通过 ACP 连接时，状态类扩展通知需要客户端在初始化时声明 statusUpdates 才会发送，会话记录路径改放在响应的 _meta 里。关联 #13721。
- 打开设置里的“派发”开关就是对派发的总同意：任务和回信不再出审批卡；新会话沿用发起会话的模型、预设、审批档位和计划模式，且不会更宽。见 #13526。
- 已装的全信任权限扩展现在也会被已安装的 MCP 工具咨询（只能收紧，不能放宽）。见 #13694。
- 常驻放行的会话间消息只会越过宿主自己设的暂停，不会越过你主动按下的暂停，它会留在队列里等你。关联 #13775。
- 本机与 SSH 项目统一展示；“打开项目”移至标题旁的加号，支持统一折叠与展开。提交 da051abb2。
- 会话采用中性选中背景；可选的悬停置顶、归档按钮默认关闭，菜单始终可用；修复环境切换、重复点击及焦点问题。PR #13638。
- 远端读取与未指定目录的打开共用主机默认目录，已有会话不会改变读取目标或绕过禁用检查。PR #13638。
- 未登记的 SSH 主机在连接前返回明确拒绝，远端写入接口的请求体限制为 64 KiB。PR #13638。

## 修复

- 代码编辑器及其查找栏的字号现在跟随外观里的界面字号，不再固定在 12px 和 11px。关联 #11577。
- 撤回反馈后，它对应的 GitHub 议题会被自动关闭（标记为不计划处理）。关联 #11995。
- 迁移数据根之后，窗口里仍记着旧位置的会话现在能按文件名在新的会话目录里打开，不再提示“没有这个会话”。关联 #13152。
- `[[keep]]` 标记的回合现在有自己的保留预算（窗口的 15%，新的优先），超出的旧回合并入摘要并提示；共享窗口的模型在回复空间用尽前就会压缩。见 #13320、#12773。
- 压缩时摘要请求被供应商以“输入超长”拒绝，现在会按更小的输入重试（70%、50%、35%），而不是放弃这次压缩。见 #13320。
- 有系统沙盒把 shell 限在项目文件夹里时，同一 git 仓库下两个项目里的会话不再因 bash 等无声明写入互相等待；没有沙盒（如 Windows）时仍整库互斥。见 #13335。
- 委派任务里点名了粘贴的截图（.reasonix/attachments 下的文件）时，子代理现在能收到图并切到识图模型；技能子代理也不再悄悄丢图。见 #13642。
- 刚进入窗格就打开分支菜单时，菜单会被自己的挂载收尾关掉，或一直停在加载中。关联 #13674。
- 模型调用跨项目派发被拒时，会说明是“允许模型把任务交给别的会话”开关没开，并指出设置位置，不再和“此会话无法打开别的项目”混为一谈。关联 #13677。
- 有新版本时，设置弹窗左侧列表里的「版本」一行也会出现和左下角设置图标一样的提示点，打开设置后能直接看到该点哪里。关联 #13682。
- Windows 上会话文件名含大写字母（如自定义模型名）时，顶部标题和标签总显示“新会话”。关联 #13684。
- 标题栏的搜索按钮在查找栏已打开时再点一次会关闭它，不再只是重新聚焦；快捷键和命令面板仍然是打开。关联 #13696。
- 你自己发的消息下面的操作图标（复制、改写、回退）和 AI 回复下面的一样大，不再偏小。关联 #13699。
- 侧栏搜索框有关键词时不再在失焦后收起，点搜索结果的第一下不会再因为列表上移而落空。关联 #13708。
- 技能目录顶层放了 SKILL.md 时，卸载它会把整个技能目录连同其他技能一起删掉；现在只删这一个文件。关联 #13714。
- 模型偏好里的“网页搜索”不再列出尚未添加的连接下的模型；选不了时的提示也改为“还没有添加”，不再误称“已被移出”。关联 #13806。
- HTTP 连接里输入 `!` 命令被拒后，命令会整段选中留在输入框，接着打字就是替换，下一条普通消息能直接发出。关联 #13810。
- 智能体把页面排版到比窗格更宽的视口（如 1440 宽）时，内置浏览器只显示页面左侧一部分；现在整页缩放到窗格内显示。关联 #13811。
- 智能体给内置浏览器页面设了比窗格小的视口时，页面居中显示，不再缩在窗格左上角；页面被缩小适配窗格时，智能体的点击仍落在原来瞄准的位置。关联 #13811。
- 项目文件夹或外部文件夹被移走、改名或删除后，工具调用不再返回系统原话或“无匹配”，而是明确告诉模型和界面“文件夹不在了”，并在输入框上方提示重新选择。关联 #13833。
- OpenCode Go 的新地址（opencode.ai/inference/go/…）不再因缺少会话标识而返回 400。关联 #13849。
- 自定义提供商没有声明推理档位时，/effort 不再说“不支持”，而是告诉你在该条目里写 supported_efforts。关联 #13857。
- 同一主机、不同端口的两个模型服务被合并成一个，新增的那个不显示；现在端口属于地址，各自独立显示，重复的条目也不再被丢掉。关联 #13858。
- 终端界面里，命令输出很长、或思考/回答很长时，界面会越来越卡（每次追加都复制整段文字）；现在追加开销不再随长度增长。见 #13872。
- Studio 窗口最小化时，智能体在内置浏览器里的点击被页面丢弃却报成功；现在输入前会不可见地升起窗口、之后恢复最小化（Windows）。见 #13628。
- 你在卡片上批准的、别的会话发来的消息，在发送队列被暂停时不再只入队不处理，会单独开始，更早排队的内容仍保持暂停。关联 #13775。
- 别的会话发来的消息正文里的 @ 不再被当成本地文件引用去读取，读不了的引用也不会再把发送队列暂停。关联 #13775。
- 终端里刚启动就输入 /feedback 会提示“当前会话不可用”，要先 /reload 才行；现在启动后即可用。关联 #12073。
- 用量页的「实付」不再包含订阅等价（Token Plan 之类）的估算；估算单独一行标为「等价估算」，每日明细里也并排显示。议题 #13276。
- 已选「自动下载」时，打开设置里的版本页会立即检查一次新版本并开始下载，不必再等最长一天的后台检查。议题 #13683。

<!-- lang:en -->

This release adds scheduled tasks, session moves, phone reminders, WSL remotes, a Git panel, a contribution board and rules directories, lets reasoning depth change mid-turn, and fixes browser scaling, terminal slowdown and sub-agent image reading.

## New

- `reasonix schedule add|list|tick` and friends: a read-only task runs when you confirm it in a terminal; call `tick` from your OS scheduler. Refs #11406.
- While Studio is open and visible (a window or tray icon), it runs the schedules you confirmed; only one kernel ticks at a time. Refs #11406.
- A conversation can be moved up or down from its menu or with Alt+Arrow on its row; the order is kept by the kernel and survives restarts. Refs #11420.
- Linux gets an `.AppImage` download for amd64 and arm64 that runs in place. It does not update itself: download the next release. Refs #11653.
- Full-screen browser and workbench with the conversation folded away; Esc or the button restores the split, and it exits by itself when something needs your decision. Refs #11721.
- phones on the same account can be reminded when an action awaits approval, the model asks, or a turn fails; only the kind and a count are sent. Off by default on both sides. Refs #11878.
- When an MCP server refuses a call for lack of access, the model stops and you can click "Grant more access" on its row; you are asked every time. Refs #11959.
- You can withdraw your own report from My feedback (or /feedback withdraw in the terminal); its issue is closed, and a report with an outcome can no longer be withdrawn. Refs #11995.
- An optional level-up notice (Settings "Tell me when my level goes up", off by default): one note at the top of the window, one line in /feedback list. Refs #12025.
- In a My feedback thread, your level badge now sits beside your own replies and never beside a maintainer's. Refs #12025.
- On a linked device, My feedback also lists reports and replies from your other linked devices; the terminal gains /feedback link, unlink, links. Refs #12073.
- Settings, Remote can add a WSL distribution on this PC. The kernel runs in it and stops with it when Studio closes; conversations are kept. Refs #12225.
- In the terminal /mcp panel, press a to sign in to a server that answered 401, or u to grant one the extra access it asked for; you are asked first. Refs #12357, #11959.
- ACP sessions accept `additionalDirectories`, so a multi-folder workspace can give a session extra write roots, for that session only and with the usual vetting. Refs #13114.
- ACP supports `$/cancel_request`, `messageId` on chunks and tool names on permission requests, and forwards MCP forms and pages when advertised. Refs #13114.
- Opt-in trace export: once your user config enables it and names a collector, each turn goes to your own observability stack as OpenTelemetry traces; off by default. Refs #13115.
- A contribution board in the feedback panel, ranked per release; you choose to join, preview the name and can leave. Terminal: /feedback board. Refs #13142.
- Move a conversation to another project from its menu; permissions, checkpoints, task logs and queued messages stay behind and are removed. Refs #13370.
- A Test connection button beside the SearXNG address says why an instance does not answer; it tests only the saved one, never a metadata address. Refs #13541.
- Large files use native references or streaming; the default 1 GiB upload safety ceiling is user-configurable. Refs #13544.
- (experimental, not run against the real endpoint) a native Gemini provider on the Interactions API with thinking, tools and video. Refs #13615.
- a Settings switch (off by default) to hand a public video address you wrote to the model vendor, which visits it itself; Zhipu GLM and Gemini (YouTube). Refs #13616.
- a sub-agent's panel row, full-record header and nested card now show the model and effort it actually ran on, failed or interrupted runs included. See #13640.
- The model can now ask you to turn on a switch it needs (such as dispatching to another project), applied only when you confirm; boundary settings it can never change. Refs #13678.
- Type # in the message box to reference a past conversation of this workspace as read-only material; search hits can be referenced too, with a size limit in Settings. Refs #13687, #11942.
- The model can give a running sub-agent more guidance with task's task_id, read at its next tool call; Settings sets the size and per-minute limits. Refs #13693.
- A mod's install preview states full trust and a static listing; a mod can draw a band above the prompt, and its questions say whose they are. Refs #13694.
- Hovering your own message now shows when it was sent next to its action icons, so a long-running task's start can be checked against it. Refs #13697.
- Settings > Extensions can remove a skill of your own or the project's, after a confirmation naming the place to be deleted; built-in and package skills do not offer it. Refs #13714.
- The terminal's /mcp panel can now add and remove MCP servers (n, d), showing the full command it would run and asking you to confirm first. Refs #13754.
- A Git panel in the workbench: a folder tree of changes to stage and discard, push with a preview, commit details, and a section per repository. Refs #13821.
- In the terminal, /btw <question> asks a read-only side question: the answer is shown once and is not saved to the session or sent into its prompt. Refs #7950.
- `reasonix acp --permission-mode`, for hosts embedding Reasonix as a subagent, fixes the approval posture: clients can lower it, never raise it; a higher saved posture is clamped. Issue #13839.
- A connection can declare the format its balance endpoint answers in; a relay must pick one or shows as not configured and is not sent the key. Refs #13736.
- Settings can start new conversations in plan mode (agent.default_mode, off by default); existing conversations keep their own mode. Refs #7852.

## Changed

- a session waiting on you gives up its write claim, Auto Guard and sandbox-escape asks included; contention reaches the model and receipt, and the longest wait is a setting. See #11531.
- The task tool gains a task_id parameter, so the tool-description cache is cold once on the first turn after upgrading and then warm again. Refs #13693.
- Over ACP, a failed turn now ends with a JSON-RPC error (-32603, data.code turn_failed), not the non-standard stopReason "error". Refs #13703.
- Over ACP, opening a session with a keyless model or no provider now returns the protocol's "Authentication required" error (-32000) so clients can offer reasonix setup. Refs #13705.
- Over ACP, a turn paused as unverified now ends with end_turn, a paused outcome and a [paused] receipt at the end of the text. Refs #13706.
- Over ACP, the vendor status notifications are sent only to clients that declare statusUpdates at initialize, and the transcript path moves into the response _meta. Refs #13721.
- the Dispatch switch is your consent: tasks and replies come in with no card, and the opened session keeps the sender's model, preset, approval mode and planning, never wider. See #13526.
- existing full-trust permission extensions are now also consulted for installed MCP tools (they can only tighten). See #13694.
- A message let in by a standing release starts only over a pause the host set itself, never over one you pressed; it stays queued for you. Refs #13775.
- Local and SSH projects share one list. Open Project moves to the heading's plus button, alongside collapse/expand all. Commit da051abb2.
- Neutral session selection offers opt-in hover Pin and Archive, off by default; session menus remain available. Environment routing, repeated clicks, focus and stream budgets are fixed. PR #13638.
- Remote reads and unqualified opens share the host default. Existing panes cannot redirect a read or bypass a disabled host. PR #13638.
- Unknown SSH hosts are refused before connecting; remote mutation request bodies are limited to 64 KiB. PR #13638.
