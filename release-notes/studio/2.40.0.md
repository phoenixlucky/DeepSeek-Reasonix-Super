本版本修复工作区「+」无法点击等问题，新增回合叙述设置，并让更新日志支持中英文切换。

## 新增

- 反馈对话框新增「截取当前窗口」：只在你点按钮时截一次，截图以可删除的缩略图加入附件，不会自动发送。关联 #11965。
- 侧边栏的会话列表数据现在带「最后活动时间」，可按最近使用排序或显示相对时间。关联 #12011。
- 子代理因另一个子代理占着要写的路径而排队时，现在会说明在等谁、是否因为双方都没声明 write_paths（按整个工作区处理）。关联 #12052。
- 主题包新增 `shadowFloat`，可改菜单、弹出层和对话框的投影；不设则保持内置阴影。关联 #12063。
- 图表在数据不多时，会在柱顶和折线数据点旁直接标出数值；数据多到放不下时自动不画，悬停读数仍然可用。关联 #12291。
- 侧栏里的项目现在可以拖动排序：按住项目行拖到目标位置，上沿或下沿的线指示落点；顺序保存在内核里。关联 #12300。
- 每轮结束时的「耗时」行现在同时写出这一轮的开始时间（当天只显示时分，其他日子带日期），重新载入会话后仍然保留。关联 #12728。
- 设置 > 账号新增「导出与导入配置」：无需账号，加密导出成文件、换机器时逐项导入；密钥默认不导出，必须设口令。关联 #12736。
- 设置 → 会话新增「回合间叙述」：选「详细」后，模型会在每批工具调用之间用三四行说明拿到了什么、下一步做什么；默认「简短」，行为不变。关联 #12788。
- 项目右键菜单新增「用 … 打开」：文件管理器之外，可用本机已安装的 VS Code、Cursor、IntelliJ IDEA、系统终端打开项目文件夹。关联 #12858。
- 工作台文件面板里新增「提交历史」：展开后按提交图谱列出所有分支最近的提交，带分支和标签。关联 #12913。
- 设置 → 外观新增「1.x 旧会话」开关，可把迁移来的 1.x 会话从侧栏隐藏；默认显示，不删除，搜索和已打开的不受影响。关联 #12964。
- 终端界面的 `/theme` 现在打开选择器：光标移到哪一行就即时预览，Enter 保留，Esc 还原；`/theme list` 仍列出名称。关联 #12985。
- 上下文超过压缩阈值而无内容可折叠时，现在会说明由什么占用（按类别和最大几项），不再只说「无需压缩」。关联 #13013。
- 本机 stdio MCP 服务器现在会在 `_meta["io.reasonix/writableRoots"]` 里收到你额外允许写入的目录；远程服务器不会收到。关联 #13053。
- 首次启动的设置页新增「稍后再说」：可先进入主界面，输入框上方会提示「去连接」；只对本次启动有效，下次仍会提示。关联 #13065。
- 底部「生成速度」详情新增「首字时间」（从发出请求到首个输出，由内核计时），并改为与「上下文详情」一致的行式样式。关联 #13075。
- 添加项目后会自动选中该项目并打开一个新会话（不会替你发送任何消息），无论是点「打开或新建项目」、首次提示里的按钮还是拖入文件夹。关联 #13076。
- 对话区右下角新增「回到顶部 / 跳到最新」悬浮按钮（距端不足 48px 或无需滚动时隐藏），优先跳到最近的展开块，取代原「回到最新」。关联 #13077。
- 版本页的更新内容可以在中文和英文之间切换，默认跟随界面语言；之后每个版本的发布说明都附带英文。关联 #13081。

## 变更

- 左侧图标栏和侧栏的「文件」按钮现在是开关：文件面板已展开时再点一次就收起，在别处关掉后再点会重新展开。关联 #12925。
- 撰写框的模型菜单里，服务商标题更醒目、模型行缩进，并新增按服务商的筛选标签（可多选、可清除，选择会记住）。关联 #12926。
- 应用、任务栏/Dock、启动器和托盘图标恢复为黑金配色。关联 #13004。
- 对话里的图片、输入框里待发的图片和工具截图共用一个查看器：点击放大原图，Esc 退出，焦点回到缩略图。关联 #13006、#13010。
- 设置侧栏的选中项不再带强调色、边框和左侧竖条，只是底色变深；分区标题比选项更轻，层级更清楚。关联 #13045、#13046。
- 去掉顶栏的「浏览器」按钮：「工作台」标签是唯一入口，没有运行中的网页时显示「文件 / 改动 / 浏览器」启动页，不再直接开一个空白页。关联 #13067。
- 会话行不再在悬停时显示「归档」「删除」两个小图标，界面更简洁；这两个操作仍在右键菜单里，Delete 键也照常可用。关联 #13068。

## 修复

- 模型起草提交说明失败时，提交卡片仍列出暂存的文件，输入框留空并说明原因，可以手动填写后提交。关联 #12747。
- 上下文用量改为以服务商回报的大小加上之后新增的内容为准，不再取本地估算和回报中较大的一个，估算偏大时不再虚高。关联 #12988。
- 只读的 `find ... -exec wc/grep/cat/stat ...` 不再被当成写入：它不会占用工作区写入租约，也就不会再和另一个会话正在写的文件冲突。关联 #12993。
- 模型退化成「很多句不重复的短句」（如 go. / End. / I wait.）时，重复输出检测现在也会提示；以前只认字节完全相同的循环。关联 #13001。
- 子代理浮层里每个子代理现在显示自己的任务标题（来自任务描述的首行，过长截断，悬停看全文），并行的子代理不再都只写「task」。关联 #13002。
- 切换长会话时不再弹出「扩展界面恢复失败」；只有确实丢了扩展界面才提示一次，读不出历史才报错。关联 #13011。
- 运行分析的信号轨里挨得太近的标记合并成一个带数量的标记，点开列出明细，不再排成很长的竖列。关联 #13034。
- 修复项目行上“…”按钮只有四个角能点、点中间没有反应的问题：行内的数量徽标淡出后仍然盖在按钮上，现在不再拦截鼠标。关联 #13036、#13038。
- 侧栏会话筛选旁的放大镜现在是真正的开关：再点一次会收起搜索框，不再重播弹出动画。关联 #13041。
- 侧栏「这台机器」行上打开或新建项目文件夹的“＋”按钮现在始终可见，不再要把鼠标移到行上才出现。关联 #13043、#13072。
- 修复输入框里打开分支菜单时，悬停提示卡没有收起、与菜单叠成两层阴影的问题。关联 #13044。
- 重新载入会话时读取状态失败而弹出的红色提示，在之后同一读取成功时会自动消失，不用再手动点“知道了”。关联 #13047。
- 设置没生效、链接打不开等不阻断发送的失败，改为右下角的小提示（最多 3 条，点“知道了”才消失），可一键“报告此问题”。关联 #13047、#13048。
- 扩展界面、MCP 目录和改动文件三处读取遇到缺失的列表字段时按空列表处理，不再弹出「Cannot read properties of undefined (reading 'filter')」。关联 #13055。
- 分支列表、事件回放和待发队列在为空时现在返回空列表而不是 null，页面不再因此在读取时出错。关联 #13055。
- 报错条与右下角提示的「报告此问题」现在会把页面自身错误的名称和出错位置（仅文件名与行列号）一并填进反馈草稿，便于定位。关联 #13055。
- 输入框下的红色提示若是页面自身的程序错误（如“Cannot read properties of undefined”），现在会把调用栈写进控制台，便于定位。关联 #13055。
- 手机远控页上传较大的图片或文件时，不再把连接弄断：过大的内容会在手机上直接提示并留在原处，其他操作照常。关联 #13056。
- 手机远控页现在可以上传较大的图片和文件：内容拆成多条消息发送，电脑端收齐后一次处理（最大 16 MB）；旧版电脑端仍提示太大。关联 #13056。
- 修复写入会话临时目录等工作区外位置时反复弹出“检查点记录失败”的提示：这类写入不在检查点范围内，改为记为覆盖缺口。关联 #13060。
- 修复 MCP 服务器启动或重连失败时内核崩溃退出的问题：失败现在只会让这个服务器不可用，不会影响其他功能。关联 #13086。
- 修复部分 Windows 电脑上界面图片（如左上角字标）显示为破损图片的一个可能原因：页面文件的类型不再受注册表里别的程序设置的影响。关联 #13094。

This release fixes the unclickable workspace "+" button, adds a turn-narration setting, and lets the changelog switch between Chinese and English.

## New

- The feedback dialog gains "Capture this window": it takes one picture of the app window only when you click, adds it as a removable thumbnail, and never sends it on its own. Refs #11965.
- The session tree now carries each conversation's last-activity time, so a list can sort by recency or show a relative time. Refs #12011.
- A sub-agent queued behind another's write claim now says whose claim it waits on, and whether neither declared write_paths (each treated as writing the whole workspace). Refs #12052.
- Theme packs gain `shadowFloat`, the shadow menus, popovers and dialogs cast; unset keeps the built-in one. Refs #12063.
- Charts now write each value beside its bar or line point while the plot is sparse, and draw none when there are too many marks to read; hover readout is unchanged. Refs #12291.
- Projects in the sidebar can now be reordered by dragging a row; a line on the target's top or bottom edge shows where it lands, and the order is kept by the kernel. Refs #12300.
- The "Worked for" line at the end of a turn now also says when the turn began (time of day for today, with the date for another day), and it survives reopening the session. Refs #12728.
- Settings > Account gains "Export and import config": no account needed; export an encrypted file and import it item by item elsewhere. Keys off by default; a passphrase is required. Refs #12736.
- Settings → Session gains "Narration between tool calls": Detailed asks the model for three or four lines between batches of tool calls; Brief, the default, changes nothing. Refs #12788.
- The project menu gains "Open with …": besides the file manager, open a project folder in the VS Code, Cursor, IntelliJ IDEA or system terminal this machine has installed. Refs #12858.
- The workbench explorer gains a "Commit history" section: opened, it lists the newest commits of every branch as a graph, with branches and tags. Refs #12913.
- Settings → Appearance gains a "Sessions from 1.x" switch to hide migrated 1.x sessions from the sidebar; shown by default, nothing is deleted. Refs #12964.
- In the terminal UI, `/theme` now opens a picker that previews each row as you move, keeps it on Enter and restores the original on Esc; `/theme list` still prints the names. Refs #12985.
- When the context is over the compaction threshold with nothing to fold, a notice now says what holds the tokens, by class and largest items. Refs #13013.
- Local stdio MCP servers now receive the extra folders you allowed tools to write in `_meta["io.reasonix/writableRoots"]`; remote ones do not. Refs #13053.
- First-run setup gains "Not now": open the workbench first, with a note above the input box leading back to setup; this launch only, offered again next time. Refs #13065.
- The bottom "Generation speed" detail gains "Time to first token" (request sent to first output, timed by the kernel) and now uses the same row layout as the context detail. Refs #13075.
- Adding a project now selects it and opens a new session in it (nothing is sent for you), whether through "Open or create project", the first-run prompt or a folder drop. Refs #13076.
- New floating "Back to top" / "Jump to latest" buttons in the conversation (hidden near an end or when nothing scrolls) land on the nearest expanded block first. Refs #13077.
- The Versions page can switch a release's notes between Chinese and English, following the interface language by default; every release's notes now carry English. Refs #13081.

## Changed

- The Files button in the rail and sidebar now toggles: pressed while the files panel is open it folds it, and it reopens after the panel was closed elsewhere. Refs #12925.
- The composer's model menu now sets provider headings apart, indents the models, and adds multi-select provider chips that are remembered. Refs #12926.
- Restore the black-and-gold application, taskbar/Dock, launcher and tray icons. Refs #13004.
- Sent pictures, pictures waiting in the composer and tool screenshots share one viewer: open the original, Esc to leave, focus returns. Refs #13006, #13010.
- The Settings sidebar's selected row no longer carries the accent colour, outline and edge bar, only a deeper fill; section titles are lighter than the items under them. Refs #13045, #13046.
- The title-bar Browser button is gone: the Workbench tab is the one way in, and with nothing running it shows the Files / Changes / Browser start page instead of opening a blank page. Refs #13067.
- Session rows no longer show the hover Archive and Delete icons; both stay in the right-click menu, and the Delete key still works. Refs #13068.

## Fixed

- When the model cannot draft a commit message, the commit card still lists the staged files and says why; type the message and commit. Refs #12747.
- The context gauge now reads the provider's reported size plus what grew since, instead of the larger of that and the local estimate, so an estimate running high no longer inflates it. Refs #12988.
- A read-only `find ... -exec wc/grep/cat/stat ...` is no longer treated as a write, so it does not claim the workspace write lease or collide with another session's edit. Refs #12993.
- The repeated-output guard now also flags a stream that collapses to a few tiny lines in no fixed order; before it only saw byte-identical loops. Refs #13001.
- Each sub-agent in the sub-agents popover now shows its own task title (the first line of its description, cut to fit, full text on hover), so parallel ones no longer all read "task". Refs #13002.
- Switching to a long session no longer shows "could not restore extension surfaces"; you hear once only if a surface was dropped. Refs #13011.
- On the run-analysis signal rail, marks too close together now share one counted marker that opens a list, instead of stacking into a tall column. Refs #13034.
- Fixed the project row's "…" button answering only at its corners: the faded count badge kept sitting over it and taking the click; it no longer takes the pointer. Refs #13036, #13038.
- The magnifier beside the session filters is now a real toggle: pressing it again closes the find box instead of replaying its opening animation. Refs #13041.
- The "+" that opens or creates a project folder on the sidebar's "This machine" row is now always visible instead of appearing only when the row is hovered. Refs #13043, #13072.
- Fixed the branch hover card staying on screen under the branch menu and stacking a second shadow. Refs #13044.
- The red notice raised when reading the session status fails on reload now clears itself when that read next succeeds, instead of waiting for "Got it". Refs #13047.
- Failures that do not block sending now show as corner notices (three at most, dismissed only by you) with "Report this problem". Refs #13047, #13048.
- The extension-surface, MCP catalog and changed-files reads treat a missing list as empty instead of raising "Cannot read properties of undefined (reading 'filter')". Refs #13055.
- The branch list, event replay and queue now answer an empty list instead of null when they are empty, so the page no longer fails reading them. Refs #13055.
- The "Report this problem" entry on error bars and corner notices now also writes a page defect's error name and where it came from (file name and line only) into the feedback draft. Refs #13055.
- A red notice under the composer that comes from a defect of the page itself (for example "Cannot read properties of undefined") now also logs its stack to the console. Refs #13055.
- Uploading a large image or file from the phone remote page no longer drops the connection: an oversized request is refused on the phone with a clear message and the link keeps working. Refs #13056.
- The phone remote page can now upload larger images and files, sent as several messages and handled once the desktop has them all (up to 16 MB). Refs #13056.
- Fixed the repeated "Checkpoint recording failed" warning for writes outside the workspace, such as the session temp folder: they are now a coverage gap, not a failure. Refs #13060.
- Fixed the kernel crashing when an MCP server fails to launch or reconnect: a failed server now only becomes unavailable, nothing else is affected. Refs #13086.
- Fixed one likely cause of broken images (such as the sidebar wordmark) on some Windows machines: the page's file types no longer follow other programs' registry entries. Refs #13094.
