本版本新增会话概览、从源文件夹更新技能、更新提醒、按模型填写价格、子代理乐观写入范围和从分支创建独立工作区副本，并修复停止卡住、后台任务状态、同仓库项目互相等待写入、压缩恢复和一批界面问题。

## 新增

- 「我的反馈」新增「账号关联」：登录后可手动把这台电脑关联到账号，随时解除；默认关闭、不改变额度，网页账号页之后据此显示反馈等级。关联 #13141。
- 会话右键菜单新增“从最近回复分叉”，会话还在执行时也能从最近一个已完成的回复分叉；旧回复下的分叉按钮执行中同样可用。关联 #13177。
- 新增：侧边栏会话右键菜单加入“自动命名”，一步生成并保存标题，无需先打开重命名，关联 #13195
- 新增：设置 › 会话折叠 › 思考过程新增「收起并预览首句」，收起的思考在同一行后面显示首句（超长以 … 截断）。默认不变。关联 #13212。
- 新增：网页版 Studio 页面开着不关、内核升级后，会提示“这个页面不是最新版”并给出刷新按钮，不再出现 n.filter 之类的报错，关联 #13213
- 新增：删除带有恢复副本的会话时，确认框可以选择“连同 N 份副本删除”，不用再一个一个删，关联 #13221
- 新增：文件窗口里可以用“用其他程序打开项目”菜单，在 VS Code、终端等已安装的程序中打开当前项目，关联 #13227
- 新增：内置浏览器的页签可以双击重命名，不再只能显示网址，关联 #13228
- 新增：Windows 上可以给「指定一个可执行文件」填写启动参数（例如 wsl.exe -d 发行版 -- /bin/bash），保存前带着参数实际运行验证，无法运行则不保存。关联 #13247。
- 新增：右侧文件窗口的工具栏加了“在系统文件管理器中显示此文件”按钮，不用再去文件列表里右键，关联 #13255
- 新增：回复反馈时可以附上截图（粘贴或选择，最多 3 张），只发给维护者，由维护者决定是否公开。关联 #13258。
- 新增：可以从选定的分支创建独立的工作区副本，指定的分支不存在时会明确提示。关联 #13271。
- 新增：设置里「子代理的写入范围」可开启乐观模式（默认关闭）：没有声明 write_paths 的子代理不再占住整个工作区，可与主会话并发写。关联 #13274。
- 新增：连接编辑器里可以按模型填写每百万 token 的价格（输入、输出、缓存命中、货币），没价格的模型在用量里仍显示「未知」。关联 #13276。
- 新增：设置 → 版本里的“更新方式”。默认“手动”不做后台联网；选“提醒”后每天查一次版本目录，有新版本时设置图标出现小点。两种方式都不下载、不安装、不重启。关联 #13291。
- 新增：点击输入框下的“缓存”数字打开会话概览：请求、Token、缓存命中、工作时长、费用及按来源明细，各数字旁写明口径，费用不完整时只给下限。关联 #13297。
- 新增：会话概览里加上“上下文窗口”：已使用、容量、各类占比与自动压缩线，标明是下一次请求的当前值而非累计，可直达上下文详情。关联 #13297。
- 新增：技能列表会标出从某个文件夹安装的技能副本与来源文件夹是否一致（来源有更新、副本被改过、两边都改过、来源不见了）。关联 #13311。
- 新增：技能列表里，从本机文件夹复制安装的技能在来源有变化时可以“从源文件夹更新…”：先预览每个文件的改动（脚本需逐项展开），确认后才替换，失败会保留原副本。关联 #13311。

## 变更

- 侧栏底部的「发送反馈」现在用强调色加粗显示，更容易找到（不加动画；错误提示上的「报告此问题」和命令面板入口不变）。关联 #13048。
- MCP 服务器把耗时的工具调用作为任务返回时，现在会自动跟进到结果，不再返回空结果或要求任务扩展而报错。关联 #13108。
- MCP 任务超过工具超时后，会转成后台任务继续运行，可用 wait、bash_output 取结果、kill_shell 取消，不再直接超时失败。关联 #13108。
- 技能列表里，技能声明的许可（license）、运行要求（compatibility）和附加信息（metadata）现在可以展开查看；这些只是显示，不影响技能怎么运行。关联 #13110。
- 会话很多时侧栏刷新、改名更快：每次刷新不再逐个会话解析路径（Windows 上 2100 个会话约从 1.2 秒降到 0.4 秒）。关联 #13176。
- 用量页的「每日明细」现在最新一天排在最上面，不用再滚到底才能看到最近的数据。关联 #13179。
- 打开文件失败时按真实原因提示：只有文件确实不存在才说“找不到文件”；被软链接或权限拒绝的文件不再被误报为不存在。关联 #13180。
- 输入 / 弹出命令列表更快：补全命令名时不再每次读取插件包、模型和记忆数据，装了大量插件技能时尤其明显。关联 #13197。
- 输入 / 或 @ 时，上一个按键还没返回的补全请求会被取消，不再堆积占满连接。关联 #13197。
- 设置了提问超时后，提问卡片会显示“N 秒后自动跳过，点任意处保留”的倒计时，接管后消失；命令行界面同步显示。关联 #13210。
- 分支芯片区分“不是 Git 仓库”“Git 拒绝打开”“Git 没有及时响应”，并显示 Git 的原话，不再统一说不是仓库。关联 #13217。
- 启动时 Git 没及时响应不再让分支芯片整场会话都显示没有仓库：第一次读取时会再试一次。关联 #13217。
- 改进：配置文件无法读取导致设置没保存时，提示会指到「设置」里查看出错位置并修复，关联 #13220
- 优化：切换本地 Git 分支成功后立即使用切换结果更新界面，变更列表单独刷新，状态摘要的三项读取并行进行。关联 #12780。
- 改进：会话标签页里正在工作的会话状态点会呼吸闪动，已完成未读也直接由这个点表示（不再多出一个小点），关联 #13254
- 改进：带 write_paths 的子代理调用不允许的工具时，拒绝原因现在说明缘由和下一步（不要重试，改用文件工具或收尾汇报）。关联 #13269。
- 改进：压缩完成的卡片在折叠后仍占窗口很大一块时，会说明剩下的是什么（模型回复、工具输出、用户消息各多少，最大的一条是谁）。关联 #13284。
- 改进：更新下载卡住时，版本面板会说明“已重连 N 次”；重连仍无效则提示下载卡住，并给出重试或手动下载的办法。关联 #13291。
- 改变：输入框下的缓存百分比不再把服务商未区分缓存的输入算作未命中，与会话概览同一口径；这类输入多的会话读数更高。关联 #13297。
- 改进：对话右下角“回到顶部/底部”的按钮更淡更小，改为圆角方形、半透明浅底，不再是深色圆形。关联 #13303。
- 改进：给“额外可写文件夹”选择技能安装位置时，拒绝原因现在说明出路：把技能源文件夹用“登记”方式安装，并在源文件夹里修改。关联 #13311。

## 修复

- 修复超长会话里自动压缩反复放弃的问题：摘要模型没看到的改动不再被当成「摘要丢了全部改动」，由系统补记后正常折叠。关联 #13013。
- 修复：重命名或复制的文件在 Git 变更里的新增/删除行数现在能正确统计。关联 #13175。
- 修复鼠标移向状态栏里的上下文浮窗时它立刻消失、导致点不到「立即压缩」和「管理 MCP」的问题（浮窗与触发处之间的空隙现在会保持悬停）。关联 #13178。
- 修复：设置了壁纸时，标签栏下沿不再是一条生硬的横线，而是向下柔和渐隐，关联 #13194
- 修复：已过期的置顶记忆不再进入稳定前缀、不再遮蔽全局指引、也不再占用置顶字数预算。关联 #13201。
- 修复：关闭一个内核里已不存在的会话窗格时不再弹出 “no runtime r1”，按已关闭处理，关联 #13204
- 修复：电脑崩溃后会话检查点的最后一行写了一半时，不再丢掉其余完好的对话轮次。关联 #13241。
- 修复对话栏变窄时输入框工具栏（模型、思考强度、停下按钮）折成两行错位的问题：现在始终保持一行，放不下时模型名先缩略。关联 #13259。
- 修复：设置了独立的 REASONIX_HOME 时，配置编辑锁不再写到系统默认的 ~/.reasonix，保持独立目录自包含。关联 #13275。
- 修复：窗口截图的对话框已经关闭时，截图流程会安静停止，不再报“window is not defined”类错误。关联 #13285。
- 修复：「恢复旧会话」现在能导入 1.x 桌面版新存储（desktop-sessions-v5）里的会话，此前它们被悄悄跳过；无法使用的编号会列入“未导入”。关联 #13290。
- 修复：项目菜单里的“文件管理器”“终端”现在显示中文，且“用文件管理器打开”不再与“在文件管理器中显示”重复。关联 #13292。
- 修复：改动范围无法确认时，结束前的提示会说明检查解决不了它，要换用会报告路径的工具重做。关联 #13293。
- 修复：打开会话时，之前保存的压缩结果若因历史变化或模型/工作区不同而无法复用，现在会提示原因，不再悄悄改发完整历史。关联 #13295。
- 修复：Windows 上停止任务时，如果系统的 taskkill 卡住，整个“停止”不再被它无限期拖住：最多等 10 秒，之后直接结束主进程。关联 #13299。
- 修复：顶部的计划按钮不再停在标签行中间，而是靠右紧挨“辅助会话”。关联 #13302。
- 修复：停止后把同一句话再发一次，不再在待发队列里叠出多份；原来未生效的那条被重新排队，恢复后只会回答一次。关联 #13318。
- 修复：停止后台任务后，右下角的任务列表会立即刷新；对已在停止中的任务再点停止，会说明“已请求停止，进程还没退出”，不再误报“已经不在运行”。关联 #13319。
- 修复：从源文件夹更新技能后，记录写入失败会自动重试一次；仍失败时再点一次更新即可补上记录，技能不再被误判为“副本被改过”。关联 #13311。
- 修复：对话右下角“回到会话顶部/跳到最新”按钮一次点击直达两端；原来的“逐个展开块”跳法改为按住 Shift 点击。关联 #13326、#13229。
- 修复：会话概览里同一行的数字按同一高度对齐，不再因旁边格的脚注较长而下沉。关联 #13297。
- 修复：同一个 Git 仓库下的多个项目互相等待写入时，提示现在说明它们共用该仓库这一个写入域，并给出出路。关联 #13335。

This release adds a session overview, updating skills from their source folder, update notifications, per-model prices and an optimistic sub-agent write mode, and fixes stuck Stop, background-job state, projects in one repository waiting on each other and compaction recovery.

## New

- "My feedback" gains an "Account link": once signed in, link this computer yourself and unlink any time. Off by default, changes no limits. Refs #13141.
- New "Branch from the latest reply" in the session menu: a running conversation can branch from its latest finished reply, and older replies' branch buttons work mid-run. Refs #13177.
- Added: the sidebar session menu now has Auto name, which generates and saves a title in one step without opening Rename first, refs #13195
- Added: Settings › Conversation folding › Thinking gains "Folded, with first sentence", showing the first sentence after a folded thought (long ones end in …). Default unchanged. Refs #13212.
- Added: a hosted Studio page left open across an upgrade now says it is not the latest build and offers a refresh, instead of failing with errors like n.filter, refs #13213
- Added: deleting a conversation that has recovery copies now offers to delete the copies with it, instead of one by one, refs #13221
- Added: the file window has an "open the project in another program" menu (VS Code, terminal and the other programs installed here), refs #13227
- Added: built-in browser tabs can be renamed by double-clicking, instead of always showing the address, refs #13228
- Added: on Windows, "point at an executable" takes launcher arguments (for example wsl.exe -d <distro> -- /bin/bash), verified by running them before saving. Refs #13247.
- Added: the file window in the right sidebar has a "show this file in the system file manager" button in its toolbar, so you no longer need the file list right-click, refs #13255
- Added: replies to feedback can carry screenshots (paste or pick, up to 3); they go to the maintainers only, who decide whether to make them public. Refs #13258.
- Added: an isolated workspace copy can be created from a chosen branch, and an unknown branch is reported clearly. Refs #13271.
- Added: an optimistic mode for sub-agent write scope in Settings (off by default): a sub-agent with no write_paths no longer holds the whole workspace. Refs #13274.
- Added: the connection editor takes a per-model price (input, output, cache hit, currency); a model with no price still shows as unknown in usage. Refs #13276.
- Added: Settings, Version, "Update mode". Manual (default) does nothing in the background; Notify checks daily and dots the Settings icon. Neither downloads, installs or restarts. Refs #13291.
- Added: the cache figure under the composer opens a session overview: requests, tokens, cache hit, work time, cost, by source, each with its definition; incomplete cost shows a floor. Refs #13297.
- Added: the session overview shows the context window: used, capacity, share by kind and the fold line, stated as a current reading, with a way into the context details. Refs #13297.
- Added: the Skills list marks an installed skill copy that no longer matches the folder it came from: source changed, copy edited, both changed, or source gone. Refs #13311.
- Added: a skill copied from a local folder can be updated from it in the Skills list: preview each file change (scripts must be opened), confirm; a failure keeps the old copy. Refs #13311.

## Changed

- The sidebar footer's "Send feedback" is now bold in the accent colour so it is easier to find (no animation; other feedback entries unchanged). Refs #13048.
- MCP servers that answer a long tool call as a task are now followed to the result, instead of returning nothing or failing for lack of the tasks extension. Refs #13108.
- An MCP task that outruns the tool's timeout now continues as a background job you can wait on, read with bash_output or cancel with kill_shell, instead of failing on the timeout. Refs #13108.
- A skill's declared license, requirements (compatibility) and metadata can now be opened in the skills list; display only, nothing about how it runs changes. Refs #13110.
- With many sessions the sidebar refreshes and renames faster: a refresh no longer resolves every session's path (2100 sessions on Windows: about 1.2 s to 0.4 s). Refs #13176.
- The usage page's daily breakdown now lists the newest day first, so the latest figures are visible without scrolling to the bottom. Refs #13179.
- Opening a file that fails now says why: only a file that is not there is reported as missing, and one behind a refused link or a permission error is no longer called "not found". Refs #13180.
- Typing / opens the command list faster: completing a command name no longer reads plugin packages, models and memory on every keystroke, which matters most with many plugin skills. Refs #13197.
- While typing / or @, a completion request a newer keystroke has made stale is cancelled instead of piling up on the connection pool. Refs #13197.
- With an ask timeout set, the question card now counts down "skipped in N s, click anywhere to keep it" and stops once you take the question over; the terminal UI shows it too. Refs #13210.
- The branch chip tells "not a Git repository" from "Git refused to open it" and "Git did not respond", and shows Git's own words. Refs #13217.
- If Git does not answer when a session opens, the branch chip no longer says there is no repository for the whole session: the first read tries once more. Refs #13217.
- Improved: when a setting is not saved because the config file does not parse, the message now points to Settings, where the broken line is shown and can be repaired, refs #13220
- Improved: after a successful local Git branch switch, the UI uses the returned state at once and refreshes the change list on its own; the summary's three reads now overlap. Refs #12780.
- Improved: the session tab dot breathes while a session is working, and finished-but-unread is shown by that same dot (no extra small dot), refs #13254
- Improved: when a write_paths sub-agent calls a target it may not run, the refusal now says why and what to do next (do not retry; use file tools or report). Refs #13269.
- Improved: when a fold still leaves a large share of the window, its card says what the rest is made of and which single message is the largest. Refs #13284.
- Improved: when an update download goes quiet, the version panel says it reconnected N times, and if that fails says it got stuck, with a retry or manual installer. Refs #13291.
- Changed: the cache percentage under the composer no longer counts prompt the provider did not split as uncached, matching the overview; sessions with much of it read higher. Refs #13297.
- Improved: the jump-to-top/bottom buttons are lighter and smaller, rounded squares with a translucent pale fill instead of dark circles. Refs #13303.
- Improved: granting the installed-skills folder as a writable folder now explains the way forward: install the skill's source folder in register mode and edit it there. Refs #13311.

- Fixed: added and removed line counts are now correct for renamed and copied files in the Git changes. Refs #13175.
- Fixed the status-bar context card closing as the pointer moved toward it, which made "Compress now" and "Manage MCP" unreachable; the gap now keeps the hover. Refs #13178.
- Fixed: over a wallpaper the tab strip no longer ends on a hard line; it now fades softly into the conversation, refs #13194

- Fixed the composer toolbar breaking into two misaligned lines when the conversation column is narrow: it stays on one line and the model name shortens first. Refs #13259.
- Fixed: with an isolated REASONIX_HOME, config edit locks no longer go to the default ~/.reasonix; the isolated home stays self-contained. Refs #13275.
- Fixed: the window capture now stops quietly when its dialog is already gone, instead of raising a "window is not defined" error. Refs #13285.

- Fixed: the project menu now shows "File manager" and "Terminal" in your language, and no longer lists the file manager twice. Refs #13292.

- Fixed: when a saved compaction cannot be reused on opening a session, a notice now says why instead of silently sending the full history. Refs #13295.

- Fixed: the plan button in the tab row now sits at the right edge beside the side-question toggle instead of floating mid-row. Fixes #13302.
- Fixed: after a stop, sending the same words again no longer stacks copies in the held queue; the steer that did not apply is requeued, so once released it is answered once. Refs #13318.
- Fixed: after stopping a background job the task list refreshes at once, and stopping one already shutting down says so instead of claiming it is not running. Refs #13319.
- Fixed: a failed record write after a skill update is retried once; if it still fails, updating again repairs the record instead of leaving the skill marked edited. Refs #13311.
- Fixed: the jump-to-top and jump-to-latest buttons now go straight to the ends in one click; the old step through expanded blocks is Shift+click. Refs #13326, #13229.
- Fixed: in the session overview, figures on one row now share a baseline instead of sinking when the neighbouring cell's footnote is longer. Refs #13297.
- Fixed: when projects under one Git repository wait on each other to write, the notice now says they share that repository's single write domain, and how to avoid it. Refs #13335.
